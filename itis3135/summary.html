Final Project Summary

1. Meeting the Specifications

Interactive JavaScript Functionality

This website implements three dynamic JavaScript features that allow users to interact with the DOM and load content dynamically:

  • Card Gallery Lightbox (cards.html): Clicking any panther card opens a full-size image modal overlay. The user can close it by clicking the × button, clicking outside the image, or pressing Escape. The modal is built and injected into the DOM via JavaScript at runtime and includes ARIA attributes for accessibility.
  • Movie Watchlist Filter (inventory.html): JavaScript inserts filter buttons (All / Watched / Watching / To Watch) above the movie table. Clicking a button instantly shows or hides rows based on each row's watch-status class, letting the user browse only the entries relevant to them without a page reload.
  • Survey Form Validation (survey.html): On form submission, JavaScript validates that all required fields are filled and that the email is properly formatted. Inline error messages appear next to any invalid fields. When all inputs are valid the form is replaced by a personalized confirmation message, giving the user clear, immediate feedback.

CRAP Design Principles

  • Contrast: Dark text (#000 / #354f52) is used on light backgrounds (#ebebeb), and white text on dark green header/footer (#84a98c / #52796f). Link color (#2b59c3) stands out clearly against all backgrounds. Error messages use red (#c0392b) to contrast against the form background.
  • Repetition: Every page shares the same header, navigation, and footer loaded from reusable component files. The same color palette, Offside font, border-radius values, and button styles repeat across all pages to create a unified visual identity.
  • Alignment: Content is centered in a max-width container (70%) with consistent padding and margin. Tables, card grids, and form fields all align to the same horizontal rhythm. CSS Flexbox and Grid are used throughout to maintain structured, predictable layouts.
  • Proximity: Related elements are grouped visually — form labels sit directly above their inputs, filter buttons appear immediately above the table they control, and the card modal caption appears directly beneath the enlarged image. Section headings introduce content blocks with clear spacing separation.

2. Critique Feedback and Updates

The following feedback was received during peer critiques, along with the actions taken in response:

  • Navigation clarity: Reviewers noted the navigation bar had many links and could be overwhelming. In response, the nav was reorganized so the primary course pages appear first, with secondary links (hobby site, client site, CRAPpyWeb archive) placed in a separate secondary nav row, improving scannability.
  • Footer school links: Feedback indicated the footer contained links to GitHub and freeCodeCamp, which are considered school/project links and do not belong in a professional site footer. These were removed; the footer now shows only the designer credit (Randy Brown Designs), a LinkedIn link, and the three validation buttons.
  • Pages lacking interactivity: Reviewers pointed out that several content pages (cards, inventory, survey) had no JavaScript interaction. Three new JS implementations were added to address this directly: a card lightbox, an inventory filter, and survey form validation.

3. Stakeholder Needs and Future Plans

The Poised Panther website is designed to serve as a personal portfolio and demonstration platform for prospective clients and employers in the web development and design space. The primary stakeholders — potential clients and hiring managers — need to see that I can build organized, professional, interactive web experiences. The site meets those needs by showcasing a range of skills: semantic HTML structure, responsive CSS layout using Flexbox and Grid, JavaScript DOM manipulation, accessible design (ARIA attributes, WCAG compliance), and separation of concerns with modular CSS and JS files linked to HTML.

The client project (Skinner’s Recipes) demonstrates my ability to build for a real stakeholder with its own brand identity, content, and functionality separate from my course work. The hobby site (Pickup Soccer) shows range and personality, which rounds out the portfolio.

Future plans for the site include: migrating to a proper front-end framework (React, already started via the React App link), adding a contact form on the portfolio that actually sends email, expanding the client project with a searchable recipe database, and improving mobile responsiveness across all pages. I also plan to continue growing the card gallery with original artwork as the Poised Panther brand develops.
